# Orquestrador FinOps (Cloud Provisioning)

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-6DB33F?style=for-the-badge&logo=spring&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)

> O sistema é um orquestrador de FinOps que permite aos desenvolvedores solicitarem recursos de nuvem através de um catálogo com preços pré-definidos, validando automaticamente o custo projetado contra o orçamento do departamento. Caso o limite financeiro seja excedido, o pedido é bloqueado e roteado para um fluxo de revisão, onde um Arquiteto Cloud pode aprovar, adequar ou rejeitar a requisição.
